# Two-arm baseline provenance

This repository preserves the two-arm Spec Kit versus Spine + PKG harness source from `synaptixs/spine-harness` commit `fb80bb56735cedfc35ab3fcf678fdc7adc848b83` (the first committed standalone snapshot). The original source code and scenario fixtures are unchanged.

The seed omits generated `dist/` archives and extracted copies, machine-specific `.env.study`, `.DS_Store`, and setup logs. They are not required to build the harness. The original commit remains the provenance record for those historical artifacts.

The original README records an 18-run stock study. That historical evidence is not a new validation of this fork. Subsequent fixes in the development repository are not included automatically.
